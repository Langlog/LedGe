# Ledge 抖音宣传逐字稿

建议时长：50—60 秒。语速稍快，画面跟随操作。

## 逐字稿

“Mac 上临时记句话，或者拖几个文件中转一下，还要先找窗口、建文件夹，真的很打断思路。

所以我做了 Ledge。它平时完全隐藏在屏幕底部，不占 Dock，也不挡桌面。

鼠标靠近底边，只会滑出一个很小的绿色标签。点一下确认展开，默认就是便签，随手输入，内容会自动保存在这台 Mac 上。复制、粘贴、全选都支持，用完按一下 ESC，窗口马上收回。

如果你拖的是 Finder 文件，Ledge 会自动切到文件中转站。可以一次拖多个文件和文件夹，放进去以后原位置就消失了；需要时再拖出来，文件会正常移动到你想放的位置，不是快捷链接。

它还支持深色模式、多显示器、登录启动和唤醒灵敏度设置。成功拖出后会自动清理中转记录。整个应用原生、轻量、完全本地运行，不上传便签和文件。

这就是 Ledge，把 Mac 屏幕底边变成一个随叫随到的临时工作台。”

## 镜头提示

1. 0—5 秒：桌面上来回找窗口，配合第一句痛点。
2. 5—12 秒：展示空桌面，指针移到底部，小绿标签滑入。
3. 12—25 秒：点击标签、输入便签、按 ESC 收回。
4. 25—40 秒：从 Finder 一次拖入多个项目，再拖到另一个文件夹。
5. 40—50 秒：快速扫过 Settings 和深色模式。
6. 50—60 秒：回到干净桌面，显示应用名和联系邮箱。
